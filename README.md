# SOVA — نظام إدارة المعارض

نظام الإدارة الداخلي لـ **محور الأعمال المتكاملة (SOVA Exhibition)**، CR# 1636161، مسقط، سلطنة عُمان.

## ماذا يفعل النظام

| الصفحة | الرابط | الوظيفة |
|---|---|---|
| لوحة التحكم | `/dashboard` | المؤشرات المالية والتشغيلية، إشغال البوثات، آخر العارضين والمدفوعات |
| المعارض والمواعيد | `/exhibitions` | إضافة المعارض وتعديلها، وثلاث فئات للبوثات لكل منها سعرها |
| طلبات الحجز | `/bookings` | مراجعة طلبات الحجز وقبولها (يُنشأ العارض تلقائياً) أو رفضها |
| العارضون والعقود | `/exhibitors` | قاعدة بيانات العارضين مع البحث والتصفية وطباعة العقد PDF |
| المبيعات والمدفوعات | `/sales` | تسجيل الدفعات، والدخل حسب المعرض وطريقة الدفع، وفاتورة PDF |
| التقارير المالية | `/reports` | تحليل حسب التصنيف وطريقة الدفع وأداء كل معرض، مع تصدير PDF |
| واتساب SOVA | `/whatsapp` | رسائل جاهزة (تذكير بالمعرض، تأكيد الحجز، تذكير بالدفع، ترحيب، رسالة مخصصة) لعدة عارضين |
| نموذج الحجز العام | `/book` | صفحة عامة بدون تسجيل دخول يرسل منها العارضون طلباتهم |

كل المبالغ بالريال العُماني بثلاث خانات عشرية، وضريبة القيمة المضافة 5%.

## التقنيات

- **React 19** و **Vite** و **React Router**
- **Supabase** لقاعدة البيانات وتسجيل الدخول وتحديث عدّاد الطلبات لحظياً
- **jsPDF** و **html2canvas** لملفات PDF، وتُحمَّل فقط عند الطباعة
- **Vitest** للاختبارات و **ESLint** لفحص الكود
- النشر على **Netlify**

## التشغيل محلياً

```bash
npm install
npm run dev        # http://localhost:5173
```

أوامر أخرى:

```bash
npm test           # الاختبارات
npm run lint       # فحص الكود
npm run build      # بناء نسخة النشر في dist/
npm run preview    # معاينة نسخة النشر
```

## الإعدادات

بيانات الاتصال بـ Supabase موجودة في ملف `.env`:

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_PUBLISHABLE_KEY=...
```

هذه القيم **عامة** بطبيعتها، فالمفتاح المنشور (publishable) مصمم ليعمل داخل المتصفح. حماية
البيانات تتم عبر قواعد **Row Level Security** في Supabase، وليس بإخفاء المفتاح. لا تضع أي
مفتاح سري (مثل `service_role`) في هذا الملف، بل ضع القيم الخاصة في `.env.local`.

## هيكل المشروع

```
src/
  api/          كل عمليات قاعدة البيانات (exhibitions, exhibitors, payments, bookings)
  components/   مكونات الواجهة المشتركة (الأزرار، النوافذ، البطاقات، القائمة الجانبية...)
  context/      تسجيل الدخول والإشعارات المنبثقة
  lib/          الحسابات المالية، التنسيق، رسائل واتساب، ملفات PDF، الثوابت
  pages/        صفحات النظام
  styles/       التصميم (CSS)
supabase/
  schema.sql    وصف الجداول (مرجعي، مستنتج من الكود)
```

البيانات الثابتة كلها في `src/lib/constants.js`: المدن، والتصنيفات، وطرق الدفع، ورقم واتساب
الشركة، ونسبة الضريبة.

## النشر

ملف `netlify.toml` يبني المشروع (`npm run build`) وينشر مجلد `dist`، ويوجّه كل الروابط إلى
التطبيق حتى تعمل روابط مثل `/book` و `/sales` مباشرة.
